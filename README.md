# Private Finance Assistant Browser App

This sanitized version contains no prefilled personal finance figures. Enter your own figures inside the app. Data is stored in localStorage in that browser profile on that device.

## Open locally
Extract the ZIP and open `index.html` in a modern browser. Some browser features such as installability require HTTPS hosting.

## Publish with GitHub Pages
1. Create a public repository.
2. Upload `index.html`, `manifest.json`, and `sw.js` to the repository root.
3. Repository Settings > Pages > deploy from `main` branch and root folder.
4. Open the generated HTTPS site on your phone.

## Install on Android
In Chrome on OnePlus 13, open the HTTPS site > ⋮ > Add to Home screen / Install app.

## Privacy and limitations
- Personal figures are not embedded in the published files and are not sent to a server by this app.
- Browser local storage is not encrypted; anyone using the same browser profile may access it.
- No bank connections, cloud sync, or AI service is included.
- Export a JSON backup before clearing browser data or changing devices.
- This is a budgeting estimate, not financial advice.
